## Overview
Kumud Vihar is a front-end residential plot management and MLM broker system. It provides an interface for brokers to register, book plots, track their referral commissions, and for administrators to manage bookings and sales. 
┌─────────────────────────────────────────┐ │ [index.html] │ │ (Main Map & Plot Grid View) │ ├─────────────────────────────────────────┤ │ [app.js] │ │ (Business Logic, Auth, Plot Status) │ ├─────────────────────────────────────────┤ │ [Firebase Auth/Firestore] │ │ [Google Apps Script] │ └─────────────────────────────────────────┘


## Components
### Core Application
- **Purpose:** Core layout, modals, login flow, plot visualizer
- **Location:** `index.html`, `style.css`
### Business Logic
- **Purpose:** Handles Firebase auth, Firestore syncing, Google App Script Webhook integrations, plot rendering, and multi-level marketing (MLM) commission distribution.
- **Location:** `app.js`
### Informational Pages
- **Purpose:** Static pages detailing project info and past media.
- **Location:** `about.html`, `past-developments.html`
## Data Flow
1. **Authentication:** User logs in via Google (Firebase Auth). `app.js` fetches broker profile from Firestore `brokers` collection.
2. **Plot Interaction:** User interacts with SVG map or Grid. Status is evaluated (Available, Pending Approval, Booked, Registered, Sold).
3. **State Management:** Modals fire actions (e.g., `submitBooking()`). Actions update local `globalPlots` array and sync immediately to Firestore `plots` collection via `saveData()`.
4. **Third-Party Syncing:** Plot sales and new broker registrations trigger a `fetch()` to a Google Apps Script webhook to update a Google Sheet.
## Integration Points
| Service | Type | Purpose |
|---------|------|---------|
| Firebase Auth | Library | Google Sign-In |
| Firestore | Library | Cloud Database syncing (plots, brokers) |
| Google Apps Script | Webhook | Syncs broker/plot data into a Google Sheet |
## Technical Debt

- [ ] No module bundler (Webpack/Vite) used. `app.js` is one large monolithic script file.
- [ ] Lack of automated testing.
